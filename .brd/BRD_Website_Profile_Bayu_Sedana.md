**Purpose:** Build a personal professional profile website that positions Bayu as an IT professional with a hybrid technical profile: software development + data/product analytics + technical consulting + mentoring.

---

# 1. Product Vision

The website should communicate one clear positioning:

> **An IT professional who understands how to build software, work with data, and translate technical problems into practical solutions.**

The site must not look like a generic AI-generated developer portfolio.

It should feel:
- professional
- technical
- analytical
- human
- credible
- modern but restrained
- suitable for software, data, product, consulting, and technical mentoring opportunities

The visual identity should avoid:
- excessive gradients
- floating glassmorphism cards everywhere
- neon colors
- excessive animated blobs
- fake terminal/code decoration
- excessive icons
- generic "AI portfolio" layouts
- unnecessary 3D objects
- overuse of rounded cards
- excessive motion

# 15. DARK / LIGHT MODE

Provide:
- Light mode
- Dark mode
- System preference support

Use a restrained professional palette.

Light:
- off-white / white background
- near-black text
- muted gray secondary text
- one restrained accent color

Dark:
- deep charcoal background
- soft white text
- muted gray secondary text
- same accent family

Do not use neon cyberpunk colors.

Persist theme preference locally.

Respect `prefers-color-scheme`.

---

# 16. ANIMATION & INTERACTION

Animation philosophy:

> **Motion should explain hierarchy, not prove that the website has animations.**

Recommended:
- subtle page/section reveal
- 150–300ms hover transitions
- gentle image scale on hover
- nav underline/active indicator
- smooth theme transition
- subtle project-card elevation
- restrained timeline reveal
- subtle number/count animation only when meaningful

Avoid:
- scroll-jacking
- parallax everywhere
- spinning 3D objects
- floating blobs
- cursor-following effects
- excessive text scrambling
- fake terminal typing
- excessive stagger animations
- animations that delay content

Accessibility:
- respect `prefers-reduced-motion`
- all interactive elements remain usable without animation

# 20. ANTI-SLOP DESIGN RULES

The implementation must explicitly avoid AI-generated portfolio clichés.

### Forbidden visual patterns
- giant gradient blobs
- purple/blue AI gradients everywhere
- glassmorphism as the default UI
- excessive rounded rectangles
- giant centered "Hello, I'm..." with no substance
- floating 3D laptop
- fake code snippets as decoration
- random metric counters
- meaningless "10+ technologies" claims
- excessive icons
- excessive badges
- "AI-powered" wording without a concrete reason
- generic stock photos
- random astronaut/robot graphics
- excessive shadows
- every section being a card

### Desired visual direction
Think:
- editorial technology portfolio
- product designer + engineer documentation
- modern professional profile
- clean Swiss-inspired grid
- typography-led hierarchy
- generous whitespace
- strong alignment
- restrained color
- real project evidence
